第二关练习

1、[expr_noprec.l][expr_noprec.y]“没有优先级声明时，Bison 的默认移进策略会给出错误结果”。2+1*3 = 5 、2*1+3 = 8 对照两组计算结果，没有符号的优先级，导致移进计算的总是后来的符号，也就是栈顶的符号。下一个练习中将处理优先级问题。

2、[dangling.l][dangling.y]"处理else与if匹配优先级的问题"。使用%precedence声明表达式的优先级继续匹配，举个例子：if (1) if (2) x=1; else y=2;当匹配到x=1;之后，遇到else要不要把if (2) x=1;当成一个stmt进行归约的问题，如被归约了，后续的else就和if(1)匹配了，如果选择移进，就可以继续和if(2)进行匹配，其中的优先级决定是有%prec确定的。

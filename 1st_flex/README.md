第一关练习

1、[command.l]指定 %x COMMENT 是排他状态，进入后 [0-9]+、[a-zA-Z_]... 这些 INITIAL 规则不再生效，只有 <COMMENT> 前缀的规则和 <<EOF>> 规则起作用。嵌套靠 comment_depth 计数器。也就是实现注释的效果。

2、[yymore.l]yymore() 只影响下一次匹配的拼接，不是永久状态。每次 yymore() 之后下一次匹配的文本会追加到当前 yytext 后面。注意示例中的\，表转义。

3、[yyless.l]yyless(yyleng - 2) 把当前匹配的最后 2 个字符（即 ..）退回输入流，扫描器会重新从 .. 开始匹配，命中 ".." 规则。yyless 的参数是保留的字符数，不是退回的字符数。

4、[eof]<<EOF>> 可以加状态前缀，针对不同状态给出不同错误消息。没有前缀的 <<EOF>> 只在 INITIAL 下生效（严格说是在所有未单独声明 <<EOF>> 的状态下生效，但显式写 <<EOF>> 更清晰）。
